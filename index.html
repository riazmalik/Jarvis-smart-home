Project Overview

What is this project?

The Voice & Gesture Smart Lighting System is a computer science project designed to make lighting control easier and smarter.

The system allows a user to control lights using voice commands or hand gestures.

Project Concept

Voice → AI → ESP32 → Relay → Lights
Gesture → Computer Vision → ESP32

Connection Overview

Low Voltage Connections

  • ESP32 connected to the power rails.
  • Microphone connected to the ESP32.
  • OLED connected using I²C connections.
  • Relay module connected to ESP32.
  • Jumper wires used for connections.
  • Components share the required ground connection.

Lighting Connections

  • Four relay channels control four lights.
  • Living Room light.
  • Bedroom light.
  • Kitchen light.
  • Study Room light.
Safety Notice: The supplied wiring guide states that AC wiring should not be placed on the breadboard. AC connections should be properly insulated and enclosed in a suitable project box. 220V wiring should only be handled under appropriate qualified supervision.
